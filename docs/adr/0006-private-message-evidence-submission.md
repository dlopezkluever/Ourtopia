# Private message evidence submission

Only a conversation participant may submit one of that conversation's messages to a Dispute. The server verifies that the source conversation and disputed Exchange belong to the same Community, that both conversation participants are the Exchange participants, and that the submitter can read the message and participate in the Dispute. The submitter selects the relevant messages; a general Community conversation does not need a prior Exchange link. The server copies each selected message into append-only Dispute evidence. The snapshot records the source message ID, author, original timestamp, copied body, submitter, and submission time. Administrators and Dispute participants read the snapshot under Dispute access rules. The source conversation remains visible only to its participants; an evidence reference never grants access to adjacent messages.

MVP private messages are text records without editing or hard deletion. Message attachments and delete-for-self behavior are outside the MVP messaging flow. Separately uploaded Dispute evidence follows the Dispute's Storage access rule. Duplicate submission of the same source message to the same Dispute by the same participant returns the existing evidence record. Any later retention policy must preserve evidence already submitted to a Dispute.
